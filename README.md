## Sobre mí

Soy desarrollador de software de Piura, Perú. Me gusta crear aplicaciones y aprender cómo conectar interfaces, lógica de negocio y datos para resolver problemas de forma práctica.

Trabajo en proyectos móviles, web y backend. Entre las tecnologías que utilizo están Flutter, Dart, JavaScript, Vue.js, Java, C# y bases de datos SQL.

## En qué estoy enfocado

- Desarrollo de aplicaciones móviles con Flutter y Dart.
- Creación de interfaces web con HTML, CSS, JavaScript y Vue.js.
- Lógica de aplicaciones y servicios con Java y C#.
- Manejo de datos con SQL Server y MySQL.
- Aprendizaje continuo mediante proyectos prácticos.
