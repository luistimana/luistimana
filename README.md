## Sobre mí

Soy desarrollador de software de Piura, Perú. Me gusta crear aplicaciones y aprender cómo conectar interfaces, lógica de negocio y datos para resolver problemas de forma práctica.

Trabajo en proyectos móviles, web y backend. Mi stack incluye tecnologías multiplataforma y nativas para móvil, frameworks frontend, herramientas backend, bases de datos y servicios en la nube.

## En qué estoy enfocado

- Aplicaciones móviles para Android y desarrollo multiplataforma con Flutter, Dart y Xamarin.
- Interfaces web con HTML, CSS, JavaScript, jQuery, Vue.js, Angular, React y Bootstrap.
- Backend y APIs con Node.js, Express, PHP, Laravel, Java y C#.
- Bases de datos relacionales y NoSQL: MySQL, PostgreSQL, SQL Server, MongoDB y Firebase.
- Herramientas de desarrollo: Git, npm, Docker, Postman y ESLint.
- Servicios cloud con Microsoft Azure.
- Diseño y prototipado con Figma, Adobe Illustrator y Photoshop.
